Q15. Gzip-compressed tar archive; difference between tar and gzip
==============================================================================
$ tar -cvf step.tar archive_lab
archive_lab/
archive_lab/file2.txt
archive_lab/file3.txt
archive_lab/file1.txt
$ gzip step.tar
$ ls -l step.tar.gz
-rw-r--r-- 1 student student 270 Nov  3 02:44 step.tar.gz
$ echo '--- or in one step ---'
--- or in one step ---
$ tar -czf onestep.tar.gz archive_lab
$ ls -l onestep.tar.gz
-rw-r--r-- 1 student student 261 Nov  3 02:44 onestep.tar.gz

Difference:
  tar  = ARCHIVER: bundles many files/directories (with permissions, owners,
         timestamps) into ONE file; it does not compress.
  gzip = COMPRESSOR: compresses ONE file (or stream) only; it cannot hold a
         directory.
  Sequence: tar creates step.tar, then gzip compresses it into step.tar.gz.
  tar -z (c z f) calls gzip internally, giving the same .tar.gz in one step.

Summary of options:
  tar : c create | x extract | t list | r append | v verbose | f file | z gzip | C directory
  gzip/gunzip : compress/decompress single files (-k keep original, -t test)
  zip/unzip   : zip -r dir.zip dir | unzip -l (list) | unzip -d (target) | unzip -t (test)
